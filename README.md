# Bookmark (SillyTavern 확장)

채팅에서 문장을 드래그해 북마크로 저장하는 가벼운 확장입니다.

## 설치

실리태번 → 확장(Extensions) → **Install extension** → 아래 주소 입력

```
https://github.com/kkkangkkang-creator/Bookmark
```

설치 후 새로고침하면 전송 버튼 옆에 북마크 아이콘이, 요술봉 메뉴에 `북마크`가 생깁니다. 어느 쪽에 보일지는 패널의 설정 탭에서 고를 수 있어요.

## 사용법

- **저장**: 채팅 본문에서 문장을 드래그 → `＋ 저장` (메모까지 남기려면 `✎ 메모`)
- **메시지 전체 저장**: 메시지의 `…` 버튼 줄에 있는 북마크 아이콘. 번역된 메시지면 원문이 자동으로 연결됩니다. 목록에는 `#74 · 전문`으로 표시돼요.
- **보기**: 전체 / 캐릭터 / 현재 채팅 탭. 캐릭터·현재 채팅 탭은 `저장순 / 메시지순` 정렬 가능
- **보기 방식**: `스레드`(전문) / `블로그`(앞부분만, 누르면 펼침)
- **날짜 줄 오른쪽 기호**
  - `↗` 원본 메시지로 이동. 다른 채팅이면 전환할지 묻고 전환 후 이동. 오래된 메시지도 자동으로 불러옵니다.
  - `⋯` 복사 / 메모 / 연결 / 카드
  - `×` 삭제
- 날짜 뒤 `*`: 원본 메시지가 없음 (재생성, 메시지 삭제, 채팅 삭제). 북마크는 그대로 남고 이동 기호만 사라집니다.
- **연결 (원문/번역)**: 북마크에 같은 장면의 원문이나 번역을 하나 붙여 둡니다.
  - LLM Translator의 원문 말풍선에서 드래그하면 `＋ 추가  ↳ 연결`이 뜹니다. 방금 저장한 북마크와 같은 메시지일 때 `↳ 연결`을 누르면 바로 붙어요.
  - 예전 북마크는 `⋯ → 연결`을 누른 뒤 채팅이나 말풍선에서 드래그하면 됩니다.
- **카드**: 문장을 PNG 발췌 카드로 저장 (세로 4:5 / 정사각 1:1)
- **백업**: 설정 탭 → 내보내기 / 불러오기 (JSON). 불러오기는 합치기 방식이라 기존 북마크가 지워지지 않습니다.

## 저장 위치

- 북마크: 실리태번 사용자 폴더의 `user/files/st-bookmarks.json` (서버 저장, 여러 기기 공유)
- 설정(글꼴, 크기 등): 실리태번 설정 파일
- 브라우저에도 사본을 하나 보관해서, 서버 파일이 없어졌을 때 자동으로 복구합니다.
